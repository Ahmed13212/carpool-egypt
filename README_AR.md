# سِكّة — منصة مشاركة الرحلات في مصر

المشروع يحتوي الآن على واجهة ويب عربية RTL متجاوبة مع الموبايل والكمبيوتر داخل `apps/web/`، بالإضافة إلى الـ API الموجود في `apps/api/`.

## تشغيل الواجهة على Windows
1. ثبّت Node.js إصدار 22 أو أحدث.
2. افتح PowerShell داخل مجلد المشروع `carpool-egypt`.
3. شغّل الملف `start-web.bat` من داخل مجلد المشروع، أو نفّذ `npm run web:start` من PowerShell.
4. افتح الرابط: `http://localhost:3000`

الصفحة الرئيسية يمكن فتحها بدون قاعدة البيانات، لكن البحث الحقيقي عن الرحلات وتسجيل الدخول والحجز ونشر الرحلات يحتاج إلى تشغيل الـ API وقاعدة البيانات.

## تشغيل الـ API وقاعدة البيانات
الـ API يحتاج إلى PostgreSQL 16 مع إضافتي `postgis` و`citext`. مش لازم تستخدم Docker، لكن لازم توفر قاعدة بيانات PostgreSQL تدعم الإضافتين.

1. انسخ `.env.example` إلى `apps/api/.env`.
2. عدّل `DATABASE_URL` وضع سرًا قويًا في `JWT_ACCESS_SECRET` (32 حرفًا على الأقل).
3. تأكد أن `CORS_ORIGINS=http://localhost:3000`.
4. من مجلد المشروع نفّذ `npm install`.
5. نفّذ `npm run migrate` ثم `npm run seed -w apps/api -- --dev` لبيئة التطوير المحلية فقط.
6. شغّل `npm run build` ثم `npm run start -w apps/api`.
7. شغّل الواجهة في نافذة PowerShell أخرى باستخدام `npm run web:start`.

تفاصيل الإعداد الأصلي وأوامر إنشاء حساب الإدارة موجودة في `README.md`.

## ما الذي أُضيف؟
- صفحة رئيسية عربية بتصميم متجاوب.
- البحث عن الرحلات من الـ API، بدون نتائج وهمية.
- إنشاء حساب وتسجيل الدخول.
- عرض حجوزات المستخدم ورحلات السائق.
- التقديم كسائق وتسجيل بيانات السيارة.
- نموذج نشر رحلة من مدينة إلى مدينة باستخدام المدن الموجودة في قاعدة البيانات.
- مسار API عام للمدن: `GET /api/v1/cities`.

## قيود مهمة
- المشروع ما زال نسخة تطوير، وليس جاهزًا للنشر العام أو الاستخدام التجاري مباشرة.
- إعدادات نشر الرحلات والحجوزات متوقفة افتراضيًا، ويمكن أن يرفض الخادم العمليات حتى يفعّلها مسؤول بعد المراجعة.
- تأكيد البريد الإلكتروني يحتاج إعداد خدمة بريد فعلية.
- رفع مستندات الهوية والرخصة، والمدفوعات، والمحادثات، والتقييمات، وواجهة الإدارة الكاملة غير مكتملة.
- الإحداثيات تقريبية لمراكز المدن، وزمن الرحلة في النموذج افتراضي (3 ساعات)، وليس ناتجًا من مخطط مسارات حقيقي.
- يجب مراجعة متطلبات الترخيص والنقل وحماية البيانات في مصر قبل إطلاق المنصة.
- تعذّر إكمال تثبيت الحزم ضمن بيئة البناء بسبب انتهاء المهلة؛ تم التحقق من صياغة JavaScript، لكن لم يتم التحقق من بناء TypeScript أو اختبارات قاعدة البيانات بعد هذه التغييرات.


## النشر على الإنترنت
راجع الملف `DEPLOY_RENDER_AR.md` لإعداد API وقاعدة PostgreSQL/PostGIS على Render وربط الواجهة المنشورة على Vercel. لا تنشر أسرارًا في ملفات الواجهة أو المستودع.


## إعداد رابط Vercel الخاص بالمشروع

تم ضبط CORS في `render.yaml` للسماح بالطلبات من `https://design-sigma-lemon.vercel.app`. بعد إنشاء خدمة Render، يجب نسخ عنوان الـ API الفعلي إلى `apps/web/config.js` وإعادة نشر الواجهة على Vercel. لا يمكن تحديد عنوان Render قبل إنشاء الخدمة في حسابك.
